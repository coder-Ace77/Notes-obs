Gin provides helpers to set and read HTTP cookies on the response and request.

The `c.SetCookie()` method signature is:

```go
c.SetCookie(name, value string, maxAge int, path, domain string, secure, httpOnly bool)
```

| Parameter  | Description                                                                                                                                                   |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `name`     | The cookie name (key).                                                                                                                                        |
| `value`    | The cookie value.                                                                                                                                             |
| `maxAge`   | Time-to-live in **seconds**. Set to `-1` to delete the cookie, or `0` to make it a session cookie (deleted when the browser closes).                          |
| `path`     | The URL path the cookie is valid for. Use `"/"` to make it available site-wide.                                                                               |
| `domain`   | The domain the cookie is scoped to (e.g., `"example.com"`). Use `"localhost"` during development.                                                             |
| `secure`   | When `true`, the cookie is only sent over **HTTPS** connections. **Set this to `true` in production.**                                                        |
| `httpOnly` | When `true`, the cookie is inaccessible to client-side JavaScript (`document.cookie`), which helps prevent XSS attacks. **Set this to `true` in production.** |

For production deployments, set `Secure: true`, `HttpOnly: true`, and `SameSite: Strict` (or `Lax`) to minimize exposure to cross-site request forgery (CSRF) and cross-site scripting (XSS) attacks.

```go
import (
  "fmt"

  "github.com/gin-gonic/gin"
)

func main() {

  router := gin.Default()

  router.GET("/cookie", func(c *gin.Context) {

    cookie, err := c.Cookie("gin_cookie")

    if err != nil {
      cookie = "NotSet"
      c.SetCookie("gin_cookie", "test", 3600, "/", "localhost", false, true)
    }

    fmt.Printf("Cookie value: %s \n", cookie)
  })

  router.Run()
}
```

### Headers 

In Gin, request headers are accessed via the `*gin.Context` object. Gin provides multiple ways to retrieve these values depending on your need for case sensitivity or specific data types.

The `GetHeader()` method is the most common way to access a specific header. It is **case-insensitive**.

```go
func(c *gin.Context) {
    // Standard approach
    userAgent := c.GetHeader("User-Agent")
    
    // Manual approach via the underlying http.Header map
    // Note: http.Header canonicalizes keys (e.g., "auth-token" -> "Auth-Token")
    apiKey := c.Request.Header.Get("X-API-KEY")
}
```

For more complex requirements, you can bind headers directly to a Go `struct` using the `header` tag. This is cleaner for endpoints requiring multiple custom headers.

```go
type HeaderData struct {
    Token    string `header:"X-Auth-Token" binding:"required"`
    Language string `header:"Accept-Language"`
}

func(c *gin.Context) {
    var h HeaderData
    if err := c.ShouldBindHeader(&h); err != nil {
        c.JSON(400, gin.H{"error": err.Error()})
        return
    }
}
```

Setting headers in the response is handled through the `Header()` method. This must be done **before** calling `c.JSON()`, `c.String()`, or any other method that writes the response body.

```go
func(c *gin.Context) {
    c.Header("X-Custom-Response-Header", "Value123")
    c.Header("Cache-Control", "no-cache")
    
    c.Status(200)
}
```

To remove a header that might have been set by a middleware or the default configuration, set its value to an empty string.

Headers are frequently managed at the middleware level for concerns like **CORS**, **Security**, or **Request Tracing**.

```go
func SecurityHeadersMiddleware() gin.HandlerFunc {
    return func(c *gin.Context) {
        c.Header("X-Frame-Options", "DENY")
        c.Header("X-Content-Type-Options", "nosniff")
        c.Header("Referrer-Policy", "strict-origin-when-cross-origin")
        
        c.Next() // Continue to the next handler
    }
}
```

### CORS

CORS set up can be done by setting the `headers`. 

```go
func CORSMiddleware() gin.HandlerFunc {
    return func(c *gin.Context) {
        // 1. Set the origins you want to allow
        c.Writer.Header().Set("Access-Control-Allow-Origin", "*") // Use specific domain in production!
        
        // 2. Allow credentials (cookies/auth headers)
        c.Writer.Header().Set("Access-Control-Allow-Credentials", "true")
        
        // 3. Define allowed headers
        c.Writer.Header().Set("Access-Control-Allow-Headers", "Content-Type, Content-Length, Accept-Encoding, X-CSRF-Token, Authorization, accept, origin, Cache-Control, X-Requested-With")
        
        // 4. Define allowed methods
        c.Writer.Header().Set("Access-Control-Allow-Methods", "POST, OPTIONS, GET, PUT, DELETE")

        // 5. Handle the OPTIONS preflight request
        if c.Request.Method == "OPTIONS" {
            c.AbortWithStatus(204) // Return 204 No Content for preflight
            return
        }

        c.Next()
    }
}
```


Or a way is to use `cors` package.

```go
go get github.com/gin-contrib/cors
```

```go
import (
    "github.com/gin-contrib/cors"
    "github.com/gin-gonic/gin"
    "time"
)

func main() {
    router := gin.Default()

    // Configuration for the middleware
    router.Use(cors.New(cors.Config{
        AllowOrigins:     []string{"http://localhost:3000", "https://myapp.com"},
        AllowMethods:     []string{"GET", "POST", "PUT", "PATCH", "DELETE", "OPTIONS"},
        AllowHeaders:     []string{"Origin", "Authorization", "Content-Type"},
        ExposeHeaders:    []string{"Content-Length"},
        AllowCredentials: true,
        MaxAge:           12 * time.Hour, // Cache the preflight response for 12 hours
    }))

    router.GET("/ping", func(c *gin.Context) {
        c.String(200, "pong")
    })

    router.Run()
}
```

**Response Codes:** Ensure your preflight (OPTIONS) returns a success code (200 or 204). If your Auth middleware blocks the OPTIONS request because it doesn't have a token, the CORS check will fail.

**Pro-Tip:** Always put CORS middleware _before_ Auth middleware. The OPTIONS request does not carry the Authorization header, so your Auth middleware would reject it before CORS ever had a chance to tell the browser it was allowed.
