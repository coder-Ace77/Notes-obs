Before we can start our coding we need setup. Python projects are best to be used with virtual environments. Its like all the dependencies are not installed globally but rest in local folder.

To create a virtual env

```bash
python3 -m venv .venv
```

In this command `python3` is the running script and `-m` means to call a module as script. `venv` is python module comes with python and final argument `.venv` is the name of virtual environment. That command creates a new virtual environment in a directory called `.venv`.

Now any terminal session initially points to the global environement by default when started. We neeed to point that we are using this virtual environment. Once virtual env is created it contains three important folders.
- `bin` - It contains python executable or the symbolic link to actual executable. And secondly this folder contains scripts to activate and deactivate the virtual environment. 
- `/lib/pythonX.X/site-packages` - When something is installed using `pip`. Installed dependencies go here. 
- `/pyvenv.cfg` - A small config file that tellls python that its actually a virtual env and points back to the real python env. 

To activate means to start using virtual environment we need to point to the virtual environment's python. Usual method is to do -

```bash
source .venv/bin/activate
```

Activate script when runned updates the `$PATH` variable. Remember that `$PATH` variable contains lists of folders to search to find the command. So when python is called now it will running from `virtual env` not global one. `source` prepends your virtual environment’s `bin/` folder to the very beginning of that list. Now, when you type `python`, the computer finds the one in your sandbox first and stops looking.

The script loads a function into your memory so that when you're done, you can just type `deactivate` to strip the sandbox path away and return your terminal to normal.

Additionally the scripts like `pip` look for the environment variables `VIRTUAL_ENV` to install the dependencies into. activate script also changes that.

### Using package manager

`pip` is the default package manager. We should upgrade it via. 

```python
python -m pip install --upgrade pip
```

Note that sometimes pip might not come with certain installations of python. 

We can install packages by 

```bash
pip install "dependency[Version]"

pip install "fastapi[Standard]"
```

If version is ommited default is installed.

Addtionally we can install from requirements.txt or any text file. 

```bash
pip install -r requirements.txt
```

Example of basic requriements.txt file

```txt
fastapi
uvicorn[standard]
pydantic
motor
pymongo
python-dotenv
```

`uvicorn` is actually a python server which we will use to run. 
To run server.

```bash
uvicorn main:app --reload
```

Here main is the file name and app is the variable to which fastapi is tied to. `--reload` will watch the files and restart server with new code.
