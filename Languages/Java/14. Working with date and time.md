The modern standard is the **java.time** API (introduced in Java 8), which is immutable, thread-safe, and much more intuitive.

The `java.time` package is categorized based on what information you actually need to store.
Most of these are working on factory pattern meaning we use static methods to get the object of that type. For example `Instant timestamp=Instant.now()`. 

| **Class**           | **Use Case**             | **Example Output**                        |
| ------------------- | ------------------------ | ----------------------------------------- |
| **`LocalDate`**     | Date only (no time/zone) | `2026-03-09`                              |
| **`LocalTime`**     | Time only (no date)      | `19:58:20.451`                            |
| **`LocalDateTime`** | Date and Time (no zone)  | `2026-03-09T19:58:20`                     |
| **`ZonedDateTime`** | Date, Time, and Timezone | `2026-03-09T19:58:20+05:30[Asia/Kolkata]` |
| **`Instant`**       | A timestamp (UTC)        | `2026-03-09T14:28:20Z`                    |

```java
LocalDate today = LocalDate.now();
LocalDateTime now = LocalDateTime.now();
Instant timestamp = Instant.now(); // Best for database timestamps
```

One of the best features of the modern API is how readable it is. It uses a builder-like pattern:

```java
LocalDate tomorrow = LocalDate.now().plusDays(1);
LocalDateTime lastMonth = LocalDateTime.now().minusMonths(1);
```

To convert dates to strings (or vice-versa), use `DateTimeFormatter`.

```java
// Formatting: Object -> String
DateTimeFormatter formatter = DateTimeFormatter.ofPattern("dd-MM-yyyy HH:mm");
String formatted = now.format(formatter); 

// Parsing: String -> Object
LocalDate parsedDate = LocalDate.parse("2026-12-25", DateTimeFormatter.ISO_LOCAL_DATE);
```

Java distinguishes between "human" time (days, months) and "machine" time (seconds, nanoseconds).

- **`Period`**: Used for `LocalDate` (Years, Months, Days).
- **`Duration`**: Used for `LocalTime` or `Instant` (Hours, Minutes, Seconds).

```java
LocalDate birthday = LocalDate.of(1995, 5, 20);
Period age = Period.between(birthday, LocalDate.now());
System.out.println("You are " + age.getYears() + " years old.");
```

**Use `Instant` for Logic:** For backend logic and database storage, always use `Instant` (UTC). Convert to `ZonedDateTime` only when you need to display it to a user in their local time.

### Duration class

To get the duration between any two timestamp we use `Duration` class. Note it works as follows

```java
import java.time.Instant;
import java.time.Duration;

public Long getTime() {
    Instant timestamp = Instant.now();
    Instant tomorrow = timestamp.plusSeconds(60);    
    Duration duration = Duration.between(timestamp, tomorrow);
   
    return duration.getSeconds(); // Or .toMillis(), .toMinutes(), etc.
}
```

Duration can return the time in any format like seconds, milliseconds etc.
