By default fastapi returns data of type `application/json` and also accepts the data of the same type but we can change that. 

fastapi.Responses hold a Response object which can be used to return the Response of different type for example `plain text` etc. 

```python
from fastapi.Responses import Response

@app.get()
def func():
	return Response(content=...,media_type=...)
```

So first we need the content which the data we want to give and second is `media_type`

Media types can be - 

- text/plain
- xml
- html
- files
- streaming

Finally `Response` object can also customise the headers , cookies etc. 
Also there are specilised response types available such as `HTMLResponse()` or `PlainTextResponse()`. Response is a base class It is "content-agnostic." It doesn't assume what you are sending. If you send a string through it without extra configuration, it treats it as raw bytes or plain text.

While the `HTML reponse`This is a direct subclass of `Response`. Its only "superpower" is that it automatically sets the header `Content-Type: text/html; charset=utf-8`. This tells the browser, "Hey, don't just show this text; render it as a webpage."

Note Since `HTMLResponse` just inherits from `Response`, you can achieve the exact same result manually.

```python
from fastapi import FastAPI, Response

app = FastAPI()

@app.get("/manual-html")
def manual_html():
    data = "<html><body><h1>It Works!</h1></body></html>"
    # We have to tell the Response object what this data is
    return Response(content=data, media_type="text/html")
```

With automatic 

```python
from fastapi.responses import HTMLResponse

@app.get("/auto-html")
def auto_html():
    data = "<html><body><h1>It Works Faster!</h1></body></html>"
    # media_type is already set to "text/html" by default here
    return HTMLResponse(content=data)
```

If your endpoint _always_ returns HTML, you don't even need to wrap your string in the return statement. You can define it in the decorator.

```python
@router.get("/profile", response_class=HTMLResponse)
async def get_profile():
    return "<html><body><h1>User Profile</h1></body></html>"
```

#### Providing custom headers 

First we need to declare the field as paramter in function definition of api. These are request headers. 

```python
@router.get("/")
def fun(custom_header:str|None = Header(None))
```

Make sure to put default value of type header otherwise it will be treated as query paramter. In the headers we name them like `access-token` however python does not allows this kind of naming convention so we use understore instead of hyphen and fastapi will autoconvert them. So these are the request header which api can take.

To provide the response headers we can simply use the response object passed as the param. 

```python
@router.get("/")
def func(response:Response):
	response["headername"] = value;
	return products
```

So now whatever you assign here will get converted to headers and auto provided to the frontend as the response. 

### Redirecting req

Similarly fastapi provides the `RedirectResponse` object which can be used to redirect a request to a different page. For example 

```python
from fastapi import FastAPI
from fastapi.responses import RedirectResponse

app = FastAPI()

@app.get("/old-path")
async def old_path():
    # This sends the user to /new-path
    return RedirectResponse(url="/new-path")

@app.get("/new-path")
async def new_path():
    return {"msg": "You have been successfully redirected!"}
```

### Cookies 

Cookies can be used to store some information on the browser. Now note that whenever a backend will set some cookie on the browser for a given website. It will be stored by the browser. From the next request from the browser these cookies will be provided to the backend for every backend request. Cookies are the `key,value` pairs and key needs to a string but the value can be 

 - str, list , dict or models. 

We can set cookie as follows - 

```python
response.set_cookie(key="",value="")
```

Also we can accept the cookie by taking it as a parameter in the function. 

```python
from fastapi import Cookie
def func(response:Response , cookie:str | None = Cookie(None)):
	# cookie object has access to cookies 
	response.set_cookie(key="",value="")
	return data
```
