The exchange argument is a proof technique used to guarantee that a greedy algorithm yields a globally optimal solution. Instead of trying to construct the optimal answer from scratch, the core premise is to assume an optimal solution exists that _differs_ from the greedy solution, and then mathematically prove that transforming this optimal solution into the greedy solution will never worsen the objective function.

Given a sequence of items $S = (x_1, x_2, \dots, x_n)$ and an objective function $F(S)$ that we want to minimize, the structure of the proof relies on simulating a bubble-sort-like transformation:

1. **Define the Greedy Choice:** Establish a greedy comparator condition $C(x_i, x_j)$ that dictates the sorting order. Let $S_G$ be the sequence strictly sorted by $C$.
    
2. **Assume a Divergent Optimal Solution:** Let $S^*$ be an optimal sequence such that $S^* \neq S_G$. Because the sequences differ, $S^*$ must contain at least one **inversion**—an adjacent pair of elements $(A, B)$ where $A$ precedes $B$ in $S^*$, but the greedy comparator dictates $B$ should precede $A$.
    
3. **The Swap:** Construct a new sequence $S'$ by swapping $A$ and $B$.
    
4. **Evaluate the Delta:** Isolate the change in the objective function $\Delta = F(S') - F(S^*)$. Because the swap only affects the local neighborhood of $A$ and $B$ (leaving the prefix and suffix invariant), $\Delta$ can typically be calculated in $O(1)$ time.
    
5. **Prove Non-Increasing Cost:** Show algebraically that $\Delta \le 0$. This proves $F(S') \le F(S^*)$.
    
6. **Conclusion:** Since swapping any inversion never increases the cost, we can continually swap adjacent inversions until $S^*$ matches $S_G$ without ever increasing the objective function. Because $S^*$ was already defined as optimal, $S_G$ must also be optimal.

### Example 

You have $n$ jobs. Each job $i$ has a processing time $t_i$ and a penalty weight $w_i$. You must process them sequentially. The completion time $C_i$ of a job is the sum of the processing times of all jobs up to and including $i$. Find an ordering that minimizes the total weighted completion time:

$$ \sum_{i=1}^n w_i C_i $$

Solution - 

Suppose we have two orderings one for the strategy say (w1,t1) and (w2,t2) 

Now say scheduling `(w1,t1)` is optimal to schedule first. 
So this means - 

```
w1*t1+w2*(t1+t2)<w1*(t1+t2)+w2*t2
w1*t1+w2*t1+w2*t2<w1*t1+w1*t2+w2*t2
w2*t1<w1*t2
t1/w1<t2/w2
```

This means we should sort according to the ratio of `r=t1/w1` jobs with lower r should be scheduled first. 

Note above methodology can be used to find the custom ordering which can schedule for us.
