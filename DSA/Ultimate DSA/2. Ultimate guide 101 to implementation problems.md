These are problems where the algorithm is trivial (greedy, simulation, parsing) and the entire difficulty is translating of the english spec into the valid code without any bugs. Major mistakes which kills peoples- 

- Rules stated in prose that interact in ways the statement never spells out
- A "last element" , "only one element" case that breaks the general formula
- Debug time exploding because everything is inlined into one loop and you can't isolate the broken rule

Do keep these three in mind - 

- Phase separation - Never mix _grouping_ with _formatting_, or _parsing_ with _evaluating_. Two passes over the data is almost always cheaper in wall-clock debug time than one clever pass. If a bug appears you immediately know which phase to look at.
- Enumerate degenerate cases _before_ writing the loop - Write them as comments first. For any problem: empty, size 1, all elements identical, the last group, the exact-boundary case. Then structure the code so each degenerate case is handled **at a boundary**, not with an `if` inside the hot loop.
- Do the implementation which makes the side cases disappear. 

Now while solving any implementation heavy problem its a good idea to state the specs first as rules in the comments. Example of LC-Text Justify observe the edge cases are part of the rules as R3 and R4

```
R1. Pack greedily: as many words per line as fit with >= 1 space between each.
R2. Non-last line, >= 2 words: distribute spaces evenly; leftmost gaps get the extra.
R3. Non-last line, exactly 1 word: left-justify, pad right.
R4. Last line: single spaces, pad right.
```

Now on the implementation part we can go in phases first thing is grouping we need to group the words and that is here - 

```
len_so_far + word.size() + count_so_far <= maxWidth
```

Phase 2 is formatting which means how many spaces to put - 

```
q = S / gaps,  r = S % gaps
gap[i] = q + (i < r)      // first r gaps get one extra
```

Finally solution - 

```cpp
class Solution {
public:
    vector<string> fullJustify(vector<string>& words, int maxWidth) {
        vector<string> res;
        int n = words.size(), i = 0;

        while (i < n) {
            // ---- Phase 1: greedy pack [i, j) ----
            int j = i, len = 0;
            while (j < n && len + (int)words[j].size() + (j - i) <= maxWidth) {
                len += words[j].size();
                ++j;
            }
            int k = j - i, gaps = k - 1;

            // ---- Phase 2: format ----
            string line;
            bool lastLine = (j == n);

            if (lastLine || gaps == 0) {          // R3 + R4 collapse into one branch
                for (int t = i; t < j; ++t) {
                    if (t > i) line += ' ';
                    line += words[t];
                }
                line.append(maxWidth - line.size(), ' ');
            } else {                               // R2
                int S = maxWidth - len;
                int q = S / gaps, r = S % gaps;
                for (int t = i; t < j; ++t) {
                    line += words[t];
                    int g = t - i;                 // gap index after this word
                    if (g < gaps) line.append(q + (g < r ? 1 : 0), ' ');
                }
            }

            res.push_back(line);
            i = j;
        }
        return res;
    }
};
```

Notice how `R3` and `R4` merge into one condition.
