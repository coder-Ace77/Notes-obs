## StringBuilder and char tricks

|   |   |   |
|---|---|---|
|Task|Code|Note|
|Append|`sb.append(x)`|chainable; use in loops|
|Insert / delete|`sb.insert(i, c)`, `sb.deleteCharAt(i)`|O(n)|
|Set / get|`sb.setCharAt(i, c)`, `sb.charAt(i)`||
|Remove last|`sb.setLength(sb.length() - 1)`|backtracking undo|
|Clear|`sb.setLength(0)`||
|Letter to index|`c - 'a'`|0 to 25|
|Index to letter|`(char) ('a' + i)`||
|Digit value|`c - '0'`||
|Frequency array|`int[] f = new int[26]; f[c - 'a']++`|`new int[128]` for ASCII|
|Char tests|`Character.isDigit(c)`, `isLetter`, `isLetterOrDigit`, `isUpperCase`||
|Char to string|`String.valueOf(c)`||

A Java `char` is a 16-bit unsigned number (a UTF-16 code unit), so it behaves very much like C++. The main difference is that Java is stricter about types.

```java
char c = 'd';
int idx = c - 'a';              // 3, works exactly like C++
int code = c;                   // 100, implicit widening, no cast needed
char next = (char) (c + 1);     // 'e', cast needed: c + 1 is an int
char x = 'a';
x++;                            // fine, ++ and += cast back automatically
x += 2;                         // also fine: x is now 'd'
char bad = c + 1;               // compile error: int cannot go into char
```

## Stack, Queue, Deque, PriorityQueue

|   |   |   |
|---|---|---|
|Need|Declare|Methods|
|Stack|`Deque<Integer> st = new ArrayDeque<>()`|`push(x)`, `pop()`, `peek()`, `isEmpty()`|
|Queue (BFS)|`Queue<int[]> q = new ArrayDeque<>()`|`offer(x)`, `poll()`, `peek()`, `size()`|
|Deque|`Deque<Integer> dq = new ArrayDeque<>()`|`offerFirst/Last`, `pollFirst/Last`, `peekFirst/Last`|
|Min-heap|`new PriorityQueue<>()`|`offer`, `poll`, `peek`: O(log n) / O(1)|
|Max-heap|`new PriorityQueue<>(Collections.reverseOrder())`||
|Heap of pairs|`new PriorityQueue<>((x, y) -> Integer.compare(x[0], y[0]))`|`int[]{key, value}`|
|Heap by map value|`new PriorityQueue<>((x, y) -> map.get(y) - map.get(x))`|top-k frequent|
|Level-order loop|`for (int sz = q.size(); sz > 0; sz--)`|process one level|
|Monotonic stack|`while (!st.isEmpty() && a[st.peek()] < a[i]) st.pop();`|store indices|
|Sliding window max|`while (!dq.isEmpty() && a[dq.peekLast()] <= a[i]) dq.pollLast();`|indices in deque|

Notes: avoid legacy `Stack` and `LinkedList` as queue; `ArrayDeque` rejects `null`; `PriorityQueue` iteration is not sorted.

## Sorting and comparators

|   |   |   |
|---|---|---|
|Task|Code|Note|
|Sort primitives|`Arrays.sort(int[])`|not stable|
|Sort objects|`Arrays.sort(T[], cmp)`, `list.sort(cmp)`|stable|
|Descending|`Collections.reverseOrder()` or `(a, b) -> Integer.compare(b, a)`||
|By length|`Comparator.comparingInt(String::length)`||
|Multi-key|`Comparator.comparingInt((int[] x) -> x[0]).thenComparingInt(x -> x[1])`||
|Intervals by start|`Arrays.sort(iv, (a, b) -> Integer.compare(a[0], b[0]))`|merge intervals|
|Custom order|`(a, b) -> (b + a).compareTo(a + b)`|largest number from strings|
|Comparable class|`class P implements Comparable<P> { public int compareTo(P o) {...} }`||
|Record key|`record Edge(int to, int w) {}`|`equals` and `hashCode` included|
|Lower bound|first `i` with `a[i] >= x`: `lo = 0, hi = n; while (lo < hi) { mid = lo + (hi - lo) / 2; if (a[mid] >= x) hi = mid; else lo = mid + 1; }`|upper bound: use `>`|
|Search on answer|`while (lo < hi) { mid = lo + (hi - lo) / 2; if (ok(mid)) hi = mid; else lo = mid + 1; }`|min feasible value|

## Bit operations

|   |   |   |
|---|---|---|
|Task|Code|Note|
|AND / OR / XOR / NOT|`a & b`, `a \| b`, `a ^ b`, `~a`||
|Shift left / right|`x << k`, `x >> k`|`x << k` = x * 2^k|
|Unsigned right shift|`x >>> k`|fills with 0 (matters for negatives)|
|Test bit i|`(x >> i) & 1` or `(x & (1 << i)) != 0`||
|Set bit i|`x \| (1 << i)`||
|Clear bit i|`x & ~(1 << i)`||
|Toggle bit i|`x ^ (1 << i)`||
|Clear lowest set bit|`x & (x - 1)`|count bits loop|
|Isolate lowest set bit|`x & -x`|Fenwick tree step|
|Power of two|`x > 0 && (x & (x - 1)) == 0`||
|Count set bits|`Integer.bitCount(x)`|`Long.bitCount` for long|
|Trailing / leading zeros|`Integer.numberOfTrailingZeros(x)`, `numberOfLeadingZeros(x)`||
|Highest set bit|`Integer.highestOneBit(x)`||
|Swap without temp|`a ^= b; b ^= a; a ^= b;`||
|Single number|XOR all elements|pairs cancel: `x ^ x = 0`, `x ^ 0 = x`|
|All subsets|`for (int m = 0; m < (1 << n); m++)`|bit i of `m` = pick element i|
|Even / odd|`(x & 1) == 0`||
|Long mask|`1L << i`|`1 << i` overflows at i >= 31|
|To binary string|`Integer.toBinaryString(x)`, `Integer.parseInt(s, 2)`||

## Math and limits

|   |   |   |
|---|---|---|
|Task|Code|Note|
|Int / long max|`Integer.MAX_VALUE` (2147483647), `Long.MAX_VALUE` (~9.2e18)|`MIN_VALUE` of int: -2147483648|
|Overflow-safe mid|`lo + (hi - lo) / 2`||
|Long product|`(long) a * b`|cast before multiplying|
|Mod|`Math.floorMod(a, m)`|`%` can be negative in Java|
|MOD constant|`1_000_000_007`|`(a * b) % MOD` with long|
|Ceil division|`(a + b - 1) / b`|positives only|
|Abs / min / max|`Math.abs(x)`, `Math.min(a, b)`, `Math.max(a, b)`|`Math.abs(Integer.MIN_VALUE)` stays negative|
|Power / sqrt|`Math.pow(a, b)`, `Math.sqrt(x)`|return double; cast for exact ints|
|GCD|`b == 0 ? a : gcd(b, a % b)`|lcm = `a / gcd(a, b) * b`|
|Integer compare|`Integer.compare(a, b)`|avoids `a - b` overflow|
|Boxed equals|`a.equals(b)`|`==` is wrong above 127|

## Complexity at a glance

|                      |                                                    |                                 |
| -------------------- | -------------------------------------------------- | ------------------------------- |
| Structure            | Main ops                                           | Cost                            |
| `ArrayList`          | get / add end / insert middle                      | O(1) / O(1) amortized / O(n)    |
| `HashMap`, `HashSet` | put / get / contains                               | O(1) average                    |
| `TreeMap`, `TreeSet` | put / get / floor                                  | O(log n)                        |
| `PriorityQueue`      | offer / poll / peek                                | O(log n) / O(log n) / O(1)      |
| `ArrayDeque`         | push / pop / offer / poll                          | O(1)                            |
| Sorting              | `Arrays.sort`, `Collections.sort`                  | O(n log n)                      |
| Input size to target | n up to 10^5: O(n log n); 10^3: O(n^2); 20: O(2^n) | about 10^8 simple ops per secon |
