we have $O(n^2)$ solution of LIS

Now we can also solve LIS using binary search.

We maintain an array `tail[]` where:
- `tail[len]` = **smallest possible tail element** of an increasing subsequence of length `len + 1`.
We iterate through each number and use **binary search** to find where it fits in `tail`.

```cpp
int lengthOfLIS(vector<int>& a) {
    vector<int> tail;
    for (int x : a) {
        auto it = lower_bound(tail.begin(), tail.end(), x);
        if (it == tail.end())
            tail.push_back(x);
        else
            *it = x;
    }
    return tail.size();
}
```

Each `tail[i]` is **the smallest possible ending value** of an increasing subsequence of length `i + 1`.

By always keeping tails minimal:

- we maximize chances to extend subsequences later,
- and ensure that binary search helps find where to replace or extend efficiently.

This is `O(nlogn)` solution.

Finding the lis : To get  the lis subsequence we have to track the element indexes as well 

- `tail_idx[i]` — index in `a` of the **last element** of the smallest subsequence of length `i + 1`
- `prev_idx[i]` — index of the **previous element** in LIS ending at index `i`
- `len` — current LIS length (size of `tail`)

```cpp
vector<int> getLIS(vector<int>& a) {
    int n = a.size();
    vector<int> tail_idx;      // stores indices of tail elements
    vector<int> prev_idx(n, -1); // link to previous element in LIS

    for (int i = 0; i < n; i++) {
        int x = a[i];
        auto it = lower_bound(tail_idx.begin(), tail_idx.end(), x,
                              [&](int idx, int val) { return a[idx] < val; });
        int pos = it - tail_idx.begin();

        if (it == tail_idx.end()) tail_idx.push_back(i);
        else tail_idx[pos] = i;

        if (pos > 0)
            prev_idx[i] = tail_idx[pos - 1];
    }

    // reconstruct LIS
    vector<int> lis;
    for (int i = tail_idx.back(); i != -1; i = prev_idx[i])
        lis.push_back(a[i]);
    reverse(lis.begin(), lis.end());
    return lis;
}
```


## 0-1 knapsack problem:

We are given  `n` items, each with a `value[i]` and a  `weight[i]`. A  **knapsack** that can carry at most `W` weight.
You must **maximize total value** of selected items such that **total weight ≤ W**.

### Solution:

Now greedy solution will not exist reason being the set of choices for weigth w can be totally different from the set of choices made to have weight w-1. 

So the recurrance is - 

Assuming that all states of the first  $i-1$  items have been processed, what are the options for the  $i^{th}$  item?

- When it is not put into the knapsack, the remaining capacity remains unchanged and total value does not change. Therefore, the maximum value in this case is  $f_{i-1, j}$ 
- When it is put into the knapsack, the remaining capacity decreases by  $w_{i}$  and the total value increases by  $v_{i}$ , so the maximum value in this case is  $f_{i-1, j-w_i} + v_i$

$$f_{i, j} = \max(f_{i-1, j}, f_{i-1, j-w_i} + v_i)$$

Now since `f(i)` depends only on `f(i-1)` thus first dimention can be removed.

$$f_j \gets \max(f_j, f_{j-w_i}+v_i)$$

So the code

```cpp
for (int i = 1; i <= n; i++)
  for (int j = W; j >= w[i]; j--)
    f[j] = max(f[j], f[j - w[i]] + v[i]);
```

Again, note the order of execution. It should be strictly followed to ensure the following invariant: Right before the pair  $(i, j)$  is processed,  $f_k$  corresponds to  $f_{i,k}$  for  $k > j$ , but to  $f_{i-1,k}$  for  $k < j$ . This ensures that  $f_{j-w_i}$  is taken from the  $(i-1)$ -th step, rather than from the  $i$ -th one.

More clear code:

Here with optimized space 

```cpp
vll dp(w+1,0),prev(w+1,0);
for(int i=1;i<=n;i++){
	for(int weight=0;weight<=w;weight++){
		dp[weight] = max(prev[weight],dp[weight]);
		if(wt[i]<=weight)dp[weight] = max(dp[weight],prev[weight-wt[i]]+v[i]);
```

## Subset sum bitset optimisation:

Recall that we can write the bottom up for subset sum as

```cpp
bool subsetSum(vector<int>& a, int S) {
    int n = a.size();
    vector<vector<bool>> dp(n + 1, vector<bool>(S + 1, false));

    for (int i = 0; i <= n; i++) dp[i][0] = true;

    for (int i = 1; i <= n; i++) {
        for (int s = 1; s <= S; s++) {
            bool notTake = dp[i - 1][s];
            bool take = false;
            if (a[i - 1] <= s)
                take = dp[i - 1][s - a[i - 1]];
            dp[i][s] = take || notTake;
        }
    }
    return dp[n][S];
}
```

Now we can optimise it for it we can use one more vector to have the previsous row but carefully looking at the state calculation of inner elements observe that while calculating the values for i+1 th state say for sum =j then it will always require the sum of prev row which is less than sum. In the other words `dp[j]` will always access the prev row for sum at most j this means if we update the state in the reverse order we will always get correct result as values before it are valid for last row only. Now one thing we don't need to wory about moving the not_taken as there is just one array storing answer so it automatically has the values. 

Observe that having the one array also removes one pass. 

```cpp
bool subsetSum1D(const vector<int>& a, int S) {
    int n = a.size();
    vector<char> dp(S+1, 0);
    dp[0] = 1;
    for (int i = 0; i < n; ++i) {
        int x = a[i];
        for (int s = S; s >= x; --s)
            if (dp[s-x]) dp[s] = 1;
    }
    return dp[S];
}
```

Now the operation inside loop is just updating some values after it so we can replace it with bit operations. `dp = dp | (dp << x)`

```cpp
bool subsetSumBitset(const vector<int>& a, int S) {
    const int MAXS = 10001; // must be >= S+1
    bitset<MAXS> dp;
    dp[0] = 1;
    for (int x : a) dp |= (dp << x);
    return dp[S];
}
```

## LCS using LIS in O(nlogn):

We can very easily compute the longest common subsequence using LIS if the values in both the arrays are unique.
Idea is first to map the values to the indexes and then in any array A replace the values by the value of index. Now observe that increasing indexes in A means these indexes are also present in B and precisely in the same order. Thus it forms longest common subsequence.

```cpp
int LCS_using_LIS(vector<int>& A, vector<int>& B) {
    unordered_map<int,int> mp;
    for (int i = 0; i < B.size(); i++) mp[B[i]] = i;

    vector<int> transformed;
    for (int x : A) if (mp.count(x)) transformed.push_back(mp[x]);

    return lis(transformed); // lis using nlogn
}
```

## Cherry pickup:

Here we have to find out the maximum number of cherries we can get in a round trip in a 2d grid. During down trip we can move right-down and during up trip we can move left-up.

### Solution:

The big idea here is that while going up we may have encountered the same cell twice and thus may pick cherry twice. To solve this one idea is to move two persons at the same time from top. Now if both persons can come at the same spot they will also be there at the same time. So it is enough to keep four things in state `(x1,y1) and (x2,y2)`. Also `x1+y1==x2+y2 = time elapsed` so we can omit one state. and get the `O(n3)` solution. 

```
dp[r1][c1][r2] = maximum cherries collected
                 when player1 is at (r1, c1)
                 and player2 is at (r2, c2)
```

```cpp
int dfs(vector<vector<int>>& g, int r1, int c1, int r2) {
	int c2 = r1 + c1 - r2;
	if (r1 >= n || c1 >= n || r2 >= n || c2 >= n ||
		g[r1][c1] == -1 || g[r2][c2] == -1)
		return -1e9;
	
	if (r1 == n - 1 && c1 == n - 1)
		return g[r1][c1];
	
	int& res = dp[r1][c1][r2];
	if (res != -1) return res;
	
	int cherries = g[r1][c1];
	if (r1 != r2) cherries += g[r2][c2];
	
	int best = max({
		dfs(g, r1 + 1, c1, r2 + 1),
		dfs(g, r1, c1 + 1, r2),
		dfs(g, r1 + 1, c1, r2),
		dfs(g, r1, c1 + 1, r2 + 1)
	});
	
	res = cherries + best;
	return res;
}
```

### Shortest common supersequence

Given two strings `str1` and `str2`, return _the shortest string that has both_ `str1` _and_ `str2` _as **subsequences**_. If there are multiple valid strings, return **any** of them.

A string `s` is a **subsequence** of string `t` if deleting some number of characters from `t` (possibly `0`) results in the string `s`.

Solution - 

Idea is to again see the problem as take non - tke dp. If `s[i]==t[j]` then we can simply take single character add that to answer and move ahead. However if not that than we need to add one character from either of the string. Also `dfs` based answer reconstruction is little tricky if moving backwards. Since we can add in `O(1)` when moving back to the end so the string which is formed is `reverse` of the result. 
 
```cpp
class Solution {
public:
    string s,t;
    vector<vector<int>> dp;
    
    int rec(int i,int j){
        if(i<0 && j<0)return 0;
        if(i<0)return j+1;
        if(j<0)return i+1;
        if(dp[i][j]!=-1)return dp[i][j];
        int ans=1e9;
        if(s[i]==t[j])ans = min(ans,rec(i-1,j-1)+1);
        ans = min(ans,rec(i-1,j)+1);
        ans = min(ans,rec(i,j-1)+1);
        return dp[i][j]=ans;
    }

    void dfs(int i,int j,string &res){
        if(i<0 && j<0)return;
        if(i<0){
            auto str = t.substr(0,j+1);
            reverse(str.begin(),str.end());
            res+=str;
            return;
        }
        if(j<0){

            auto str = s.substr(0,i+1);
            reverse(str.begin(),str.end());
            res+=str;
            return;
        }
        
        if(s[i]==t[j]){
            res+=s[i];
            dfs(i-1,j-1,res);
        }else if(rec(i,j)==rec(i-1,j)+1){
            res+=s[i];
            dfs(i-1,j,res);
        }else{
            res+=t[j];
            dfs(i,j-1,res);
        }
    }

    string shortestCommonSupersequence(string str1, string str2) {
        s = str1;
        t = str2;
        int n = s.size(), m = t.size();
        dp.clear();
        dp.resize(n+1,vector<int> (m+1,-1));    
        int ans = rec(n-1,m-1);
        cout<<ans<<endl;
        string res="";
        dfs(n-1,m-1,res);
        reverse(res.begin(), res.end());
        return res;
    }
};
```

#### Solution2

This solution is the standard, optimized way to solve the **Shortest Common Supersequence (SCS)** problem using Dynamic Programming.

The core idea is that to make the supersequence as short as possible, we want to find the **Longest Common Subsequence (LCS)** and include those characters only **once**. Every other character that isn't part of the LCS must be included in the order they appear.

The length of the Shortest Common Supersequence is mathematically defined as:

$$\text{Length}(SCS) = \text{Length}(s1) + \text{Length}(s2) - \text{Length}(LCS)$$

The first half of the code fills a 2D array `dp[n+1][m+1]`, where `dp[i][j]` represents the length of the **Longest Common Subsequence** between `s1[0...i-1]` and `s2[0...j-1]`.

- **Matching Characters:** If `s1[ind1-1] == s2[ind2-1]`, we found a common character. We add $1$ to the result of the previous prefixes: `1 + dp[ind1-1][ind2-1]`.
- **Mismatch:** If they don't match, the LCS length is the maximum we can get by either skipping a character from `s1` or skipping a character from `s2`: `max(dp[ind1-1][ind2], dp[ind1][ind2-1])`.

This is the most critical part. We start from the bottom-right of the table (`i=n, j=m`) and walk backward to the top-left.

1. **If characters match (`s1[i-1] == s2[j-1]`):**
    - This character is part of the LCS.
    - We add it to our result **once**.
    - Move diagonally up-left: `i--`, `j--`.
2. **If characters don't match:**
    - We must choose which character to add to our supersequence to keep it shortest. We look at the `dp` table to see which path preserves the LCS.
    - **If `dp[i-1][j] > dp[i][j-1]`:** This means the LCS length came from `s1`. We add the character from `s1` to our result and move up: `i--`.
    - **Otherwise:** The LCS length came from `s2`. We add the character from `s2` to our result and move left: `j--`.



### Distinct subsequence 

Given a string s, return _the number of **distinct non-empty subsequences** of_ `s`. Since the answer may be very large, return it **modulo** `109 + 7`.
- `s` consists of lowercase English letters.
- `|s|<=2000` 
### Solution 

Let's try for a dynamic programming solution. In order to not repeat work, our goal is to phrase the current problem in terms of the answer to previous problems. A typical idea will be to try to count the number of states `dp[k]` (distinct subsequences) that use letters `S[0], S[1], ..., S[k]`.

Naively, for say, `S = "abcx"`, we have `dp[k] = dp[k-1] * 2`. This is because for `dp[2]` which counts `("", "a", "b", "c", "ab", "ac", "bc", "abc")`, `dp[3]` counts all of those, plus all of those with the `x` ending, like `("x", "ax", "bx", "cx", "abx", "acx", "bcx", "abcx")`. Here's a visualization for this string. 

However, for something like `S = "aba"`, let's play around with it. We have:
- `dp[0] = 2`, as it counts `("", "a")`
- `dp[1] = 4`, as it counts `("", "a", "b", "ab")`;
- `dp[2] = 7` as it counts `("", "a", "b", "aa", "ab", "ba", "aba")`

The `dp[2]` is not equal to `dp[1]*2` reason being in this `2 times` formulation any repeating character earlier will get double counted. Reason is that comming from earlier we would have already counted ending upto `a` and then when extended again here. This directly means that we need to substract this value. So we will subtract the value of last found index `j` `dp[j-1]`. Why `j-1` because the way we are extending all the subseq ending at `j-1` will get counted once in `j` and then again at current which is problem. 

```
dp[i]=2*dp[i-1]-dp[s[i] last occured] 
```

```cpp
int distinctSubseqII(string s) {
	int n = s.size();
	vector<int> dp(n+1);
	// 1 base meaning empty 
	dp[0]=1;  
	vector<int> last(26);
	for(int i=1;i<=n;i++){
		dp[i]=(2ll*dp[i-1]-last[s[i-1]-'a']+mod)%mod;
		last[s[i-1]-'a']=dp[i-1];
	}
	return (dp[n]-1+mod)%mod;
}
```

This specific paradigm is often called **"DP on Subsequences with Duplicate Handling"** or **"Counting via Complementary Counting."**

### Partition array into two arrays to minimise the sum 

You are given an integer array `nums` of `2 * n` integers. You need to partition `nums` into **two** arrays of length `n` to **minimize the absolute difference** of the **sums** of the arrays. To partition `nums`, put each element of `nums` into **one** of the two arrays.

Return _the **minimum** possible absolute difference_.

`n<=15` and `arr[i]<=10^9`

### Solution 

though this problem is not dynamic problem strctly it many times comes into the category of dp problems. 

What we can see is that we can not keep the current taken sum reason being sum is too large. Second;y array size can be upto `30` so using the bitmask dp is not possible. 

So we use the apporach of meet in the middle. Here the idea is to first divide the array into two halves. Then we will calculate the `arr1[x] = an array of different sums we can get by choosing x elements from the first n elements.`

Similarly we can calculate the `arr2[x]` as well. Now that we can then take for each element `i` in `arr[x]` then we can find nearest to `i` in `arr2[n-x]` which makes second half and also we need to be close to as `sum/2`. Which can be calculated using binary search. 

How to form the `arr1 and arr2`. Idea is to produce all the subsets using bitset all subset creation strategy. 

```cpp
class Solution {
public:
    void rec(int i,vector<vector<int>> &dp,vector<int> &v,int &sz,int &sum){
        if(i==v.size()){
            dp[sz].push_back(sum);
            return;
        }
        rec(i+1,dp,v,sz,sum);
        sum+=v[i];
        sz+=1;
        rec(i+1,dp,v,sz,sum);
        sum-=v[i];
        sz-=1;
    }
    int minimumDifference(vector<int>& nums){
        int tot=0,n = nums.size()/2;
        vector<int> v1,v2;
        for(int i=0;i<nums.size();i++){
            if(i%2){v1.push_back(nums[i]);}
            else {v2.push_back(nums[i]);}
            tot+=nums[i];
        }
        vector<vector<int>> dp1(n+1),dp2(n+1);
        int sz1=0,sz2=0,sum1=0,sum2=0;
        rec(0,dp1,v1,sz1,sum1);
        rec(0,dp2,v2,sz2,sum2);
        int ans = 1e9;
        for(auto &x:dp2)sort(x.begin(),x.end());
        for(int sz=0; sz<=n; ++sz){
            for(auto &a : dp1[sz]){
                int b = (tot - 2*a)/2, rsz = n-sz;
                auto &v = dp2[rsz];
                auto itr = lower_bound(v.begin(), v.end(),b);
                if(itr!=v.end()) ans = min(ans, abs(tot-2*(a+(*itr))));
                if(itr!= v.begin()){
                    itr=prev(itr);
                    ans = min(ans, abs(tot-2*(a+(*itr))));
                }                
            }
        }
        return ans;
    }
};
```

### Interval dp

In the interval dp `state` solves for the some interval problem. So `dp[i,j] = answer of the interval (i,j)`

Most simple example is MCM - 

##### Matrix chain multiplication

Given a chain of matrices A1, A2, A3,.....An, you have to figure out the most efficient way to multiply these matrices. In other words, determine where to place parentheses to **minimize** the number of **multiplications.**

Given an array nums of size n. Dimension of matrix Ai ( 0 < i < n ) is nums[i - 1] x nums[i].Find a minimum number of multiplications needed to multiply the chain.

Solution 

f we have a matrix $A$ of dimensions $p \times q$ and matrix $B$ of dimensions $q \times r$, the cost to multiply them is:

$$Cost = p \times q \times r$$

MCM exhibits **Optimal Substructure**: to find the optimal way to multiply a chain of length $n$, we find the optimal split point $k$ that divides the chain into two smaller optimal sub-chains.

```
Let $dp[i][j]$ be the minimum number of scalar multiplications needed to compute the matrix product $A_i A_{i+1} \dots A_j$.
```

```
To compute $dp[i][j]$, we split the product at some index $k$ (where $i \leq k < j$):

$$(A_i \dots A_k) \times (A_{k+1} \dots A_j)$$
```

The cost for this split is:

1. Cost to compute the left part: $dp[i][k]$
2. Cost to compute the right part: $dp[k+1][j]$
3. Cost to multiply the two resulting matrices: $p_{i-1} \times p_k \times p_j$ (where $p$ is the array of dimensions).

$$dp[i][j] = \min_{i \leq k < j} \{ dp[i][k] + dp[k+1][j] + p_{i-1} \times p_k \times p_j \}$$

When there is only one matrix ($i = j$), no multiplication is needed:

$$dp[i][i] = 0$$

Code

Note bottom up solution should be written so that the iteration is forst done one the length since to solve for any subseq of length `l` we need to have solution for all the cases for length `l-1`. 

```cpp
int matrixChainOrder(const vector<int>& p) {
    int n = p.size() - 1; // Number of matrices
    
    // dp[i][j] = minimum cost to multiply matrices from i to j
    // Using 1-based indexing for convenience with the dimensions array
    vector<vector<int>> dp(n + 1, vector<int>(n + 1, 0));

    // L is the chain length (from length 2 to n)
    for (int L = 2; L <= n; L++) {
        for (int i = 1; i <= n - L + 1; i++) {
            int j = i + L - 1;
            dp[i][j] = INT_MAX;

            // Try all possible split points k
            for (int k = i; k < j; k++) {
                int cost = dp[i][k] + dp[k + 1][j] + (p[i - 1] * p[k] * p[j]);
                if (cost < dp[i][j]) {
                    dp[i][j] = cost;
                }
            }
        }
    }
    return dp[1][n];
}

```
