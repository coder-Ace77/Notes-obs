### Spring boot annotation

The @SpringBootApplication annotation is the primary entry point of any Spring Boot application. It is a convenience annotation that combines three commonly used annotations in Spring:

It has three configurations inside - 

-  `@EnableAutoConfiguration` -  It tells Spring Boot to start adding beans based on the library dependencies you have added to your `pom.xml`. If Spring Boot sees `spring-boot-starter-web` on your classpath, this annotation automatically sets up an internal Tomcat server and configures Spring MVC for you.
- `@componentscan` - It triggers a search for classes annotated with `@Component`, `@Service`, `@Repository`, or `@Controller` within the current package and all of its sub-packages.
- `Configuration` - Spring needs at least _one_ class to start the application context. By marking the main class with `@Configuration` (via `@SpringBootApplication`), you are telling Spring: "Start here. This is the root of my application's world." 

Spring Boot needs to know where to start looking for your code. By passing `MyClass.class`, Spring uses it as the **Primary Source**. From that specific class, it looks up and sees the `@SpringBootApplication` annotation.

```java
package com.example.demo;

import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;

@SpringBootApplication
public class DemoApplication {
    public static void main(String[] args) {
        SpringApplication.run(DemoApplication.class, args);
    }
}
```

Now inside the packages whatever classes are there marked with the sttreotype annotations like `Component` etc will be scanned and made bean of. 

### Configuring springboot application

Configuration is a core aspect of Spring Boot that enables you to customize application behavior without changing the source code. Spring Boot provides multiple ways to configure applications,
including property files, YAML files, environment variables, command-line arguments, and more.

#### Using property files

Here the properties are defined as `key=value` pair. 

```java
server.port=8080
spring.datasource.url=jdbc:mysql//...
spring.datasource.username=root
```

Similarly we can define the yaml format. 

#### External configuration

We can also define the properties of the application via command line , environment variables. For example if the environment variables are set. 

```
export SPRING_DATASOURCE_URL=jdbc:mysql://localhost:3306/db
```

Then it will automatically be marked.

Similarly we can use command line note that we provide the properties via long naming convention of unix format and properties provided via command line have most precedence. 

```bash
java -jar myapp.jar --server.port=9090 --logging.level.root=DEBUG
```

Spring also allows us to have environment specific configurations. `dev,test,prod`. 
Eg using profiles

So we can create two files `applicaton-dev.properties` and `application-prod.properties` and then activate them using `Application.properties` putting `spring.profiles.active=dev`
or via cli `java -jar app.jar --spring.profiles.active=prod`

#### Injecting values 

Spring provides two ways to inject properties into Java classes.Using `@Value` annotation. It works like field injection however note that fields will be injected only if spring is running not if we are doing some test initialization. 

```java
@Component
public class AppSettings{
	
	@Value("${server.port}")
	private int port;
	
	@Value("${custom.message:Default message}")
	private String message;
}
```

### Springboot starters

A Starter is a pre-defined set of dependencies bundled under a single starter module, designed to support specific application needs (e.g., web, JPA, security).

example

```java
<dependency>
	<groupId>org.springframework.boot</groupId>
	<artifactId>spring-boot-starter-web</artifactId>
</dependency>
```

Common starters - 

#### `spring-boot-starter-web`

- Used to build web applications and RESTful services using Spring MVC. 
- Has jackson
- Tomcat
- spring mvc

#### `spring-boot-starter-data-jpa`

Used to enable Spring Data JPA for data access with relational databases.

It has - 
 - Spring data JPA
 - Hibernate
 - Spring ORM

#### `spring-boot-starter-security`

Used to add authentication and authorization to your application. It has spring security inbuilt. 

Others - 

 - `spring-boot-starter-test`
 - `spring-boot-starter-actuator` - Managing and monitoring
 - `spring-boot-starter-validator` - Bean validation using Hibernate Validator
