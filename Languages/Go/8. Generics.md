Go functions can be written to work on multiple types using type parameters. The type parameters of a function appear between brackets, before the function's arguments.

```go
func Index[T Constraint](s []T, x T) int
```

Note that `constraint` restrict the type that can be passed. These actually are the interfaces which dictate type that can be passed build in contraints are - 

 - any -  Alias for the `inteerface{}` empty interface it means any type is allowed. 
 - comparable - Allows any type whose value can be compared using `==` or `!=`.  (e.g., booleans, numbers, strings, pointers, channels, interfaces, and arrays/structs made of comparable types). It does _not_ support `<`, `>`, `<=`, or `>=`.

You can define custom constraints using interfaces that specify a union of types.

```go
// Number allows any standard integer or floating-point type
type Number interface {
    int | int8 | int16 | int32 | int64 |
    float32 | float64
}
```

Generic functions can operate on multiple types using the same implementation.

This declaration means that `s` is a slice of any type `T` that fulfills the built-in constraint `comparable`. `x` is also a value of the same type. comparable is a usefull constraint that makes it possible to use equality operators.  

```go
func Index[T comparable](s []T, x T) int {
	for i, v := range s {
		// v and x are type T, which has the comparable
		// constraint, so we can use == here.
		if v == x {
			return i
		}
	}
	return -1
}
```

In addition to generic functions, Go also supports generic types. A type can be parameterized with a type parameter, which could be useful for implementing generic data structures.

The type again appears after the name and input and between struct keyword. 

```go
// Stack is a generic LIFO data structure.
type Stack[T any] struct {
    items []T
}

// Push adds an item to the stack.
// Notice that the receiver must include the type parameter [T].
func (s *Stack[T]) Push(item T) {
    s.items = append(s.items, item)
}

// Pop removes and returns the top item from the stack.
func (s *Stack[T]) Pop() (T, bool) {
    if len(s.items) == 0 {
        var zero T // Retrieves the zero-value for type T
        return zero, false
    }
    
    index := len(s.items) - 1
    item := s.items[index]
    s.items = s.items[:index]
    return item, true
}
```

Usage  - Unlike in `c` where we use `<>` here we use `[]`

```go
func main() {
    // We must instantiate the type when declaring it
    var intStack Stack[int]
    intStack.Push(10)
    intStack.Push(20)
    
    val, _ := intStack.Pop()
    fmt.Println(val) // Output: 20
}
```


In Go, a **type assertion** provides access to an interface value's underlying concrete value. It is a way to tell the compiler, "I know this variable is an interface, but I am asserting that it currently holds a value of this specific type." Type assertions are most commonly used when working with `any` (or `interface{}`), where the compiler has no idea what the underlying data type is. 

The syntax for a type assertion is `i.(T)`, where `i` is an interface and `T` is a concrete type (or another interface).

If you assert a type and you are wrong, your program will **panic** and crash at runtime.

```go
var i any = "hello"

// This works because the underlying value IS a string
s := i.(string) 
fmt.Println(s)

// THIS WILL PANIC! The underlying value is not an int.
// panic: interface conversion: interface {} is string, not int
n := i.(int)
```

```go
var i any = "hello"

// Safe assertion
s, ok := i.(string)
if ok {
    fmt.Printf("It's a string: %q\n", s)
} else {
    fmt.Println("Not a string")
}

// Failing safe assertion (no panic)
n, ok := i.(int)
if ok {
    fmt.Printf("It's an int: %d\n", n)
} else {
    fmt.Println("Not an int") // This will print
    // Note: n will be the zero-value for an int (0)
}
```

When you expect an interface might hold one of several different types, writing multiple `if/else` type assertions becomes tedious. Go provides a **type switch** specifically for this scenario.

```go
func doSomething(i any) {
    switch v := i.(type) {
    case int:
        fmt.Printf("Twice the int: %d\n", v*2)
    case string:
        fmt.Printf("String length: %d\n", len(v))
    case bool:
        fmt.Printf("Boolean is: %t\n", v)
    default:
        fmt.Printf("I don't know about type %T!\n", v)
    }
}
```
