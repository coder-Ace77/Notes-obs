### For

Go has only one looping construct, the `for` loop. 

The basic `for` loop has three components separated by semicolons:

- the init statement: executed before the first iteration
- the condition expression: evaluated before every iteration
- the post statement: executed at the end of every iteration

```go
package main

import "fmt"

func main() {
	sum := 0
	for i := 0; i < 10; i++ {
		sum += i
	}
	fmt.Println(sum)
}

```

The init statement will often be a short variable declaration, and the variables declared there are visible only in the scope of the `for` statement. The loop will stop iterating once the boolean condition evaluates to `false`.

**Note:** Unlike other languages like C, Java, or JavaScript there are no parentheses surrounding the three components of the `for` statement and the braces `{ }` are always required.

All the three components are `optional`. Omit init and post statement and you get while loop. Omitting condition means its infinite loop. 

Note that first init and post are statements while condition has to be expression. 

### ifs

Go's `if` statements are like its `for` loops; the expression need not be surrounded by parentheses `( )` but the braces `{ }` are required.

```go
if x < 0 {
	return sqrt(-x) + "i"
}
```

Like `for`, the `if` statement can start with a short statement to execute before the condition.
Variables declared by the statement are only in scope until the end of the `if`.

```go
func pow(x, n, lim float64) float64 {
	if v := math.Pow(x, n); v < lim {
		return v
	}
	return lim
}
```

Variables declared inside an `if` short statement are also available inside any of the `else` blocks.

```go
if v := math.Pow(x, n); v < lim {
		return v
	} else {
		fmt.Printf("%g >= %g\n", v, lim)
	}
```

A `switch` statement is a shorter way to write a sequence of `if - else` statements. It runs the first case whose value is equal to the condition expression.

Go's switch is like the one in C, C++, Java, JavaScript, and PHP, except that Go only runs the selected case, not all the cases that follow. Syntax is `case exp:`

```go
switch os := runtime.GOOS; os {
	case "darwin":
		fmt.Println("macOS.")
	case "linux":
		fmt.Println("Linux.")
	default:
		// freebsd, openbsd,
		// plan9, windows...
		fmt.Printf("%s.\n", os)
	}
```

Switch cases evaluate cases from top to bottom, stopping when a case succeeds. Switch without a condition is the same as `switch true`. 

### Defer

A defer statement defers the execution of a function until the surrounding function returns. The deferred call's arguments are evaluated immediately, but the function call is not executed until the surrounding function returns.

```go
func main() {
	defer fmt.Println("world")

	fmt.Println("hello")
}
```

### range

It’s the idiomatic way to loop through slices, arrays, maps, strings, and channels. Instead of managing counters and boundary checks manually, `range` handles the heavy lifting and returns the data in a way that fits the collection type.

For linear collections, `range` returns two values: the **index** (the "where") and the **element value** (the "what").

```go
primes := []int{2, 3, 5, 7}

for i, v := range primes {
    fmt.Printf("At index %d, the prime is %d\n", i, v)
}
```

Note the values are the copies not the actual values. 

For maps, `range` returns the **key** and the **value**.

```go
scores := map[string]int{"Adil": 100, "Bot": 50}

for key, val := range scores {
    fmt.Printf("%s scored %d\n", key, val)
}
```

When you range over a string, Go treats it as a sequence of **Unicode Code Points (runes)**, not just raw bytes. This is the safest way to handle international text or emojis.

```go
for i, r := range "Go世界" {
    fmt.Printf("Byte index %d starts character %c\n", i, r)
}
```

Ranging over channels is a special case It only returns **one value** (the data from the channel). It will block and keep waiting for data until the channel is **closed**.

```go
ch := make(chan int)
// ... (some goroutine sends data and eventually calls close(ch))

for val := range ch {
    fmt.Println("Received:", val)
}
// Loop exits automatically once ch is closed and empty
```

Go is strict: if you declare a variable, you **must** use it. If you only care about the values in a slice (and not the indices), you use the underscore to ignore the index.

```go
for i, _ := range pow
for _, value := range pow
```

If you only want the index, you can omit the second variable.

`for i := range pow`
