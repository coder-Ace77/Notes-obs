Docker is meant to be used to create isolated envionments where application runs , these can be packaged , moved and shipped to anywhere. A docker container is said to have running a os. Infact since docker does not do full virtualization. It uses the underlying kernel this means we can run any docker container as long as it shares the same kernel with the host. 

Docker containers only contain the applciation dependencies and libraries as it gets the underlying os kernel. Virtual machines on the other hand work differently. There is a hypervisor running on top of host os and each virtual machine has its own os , libs and deps. This makes virtual machines much more bloated. 

An docker image is just the package template of the container. More formally in docker we use utf unified file system to create the image. Images in docker are created in layers. With something called as base layer. Then for each command you write in the dockerfile it creates one new layer which is essentially a new layer of filesystem.
