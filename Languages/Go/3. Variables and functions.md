Now to declare the variables:

```go
var <var name> <type>
```

We can also assign the values using the `"="` operator

```go
var max_length integer = 100
```

However note that go is static typed so left hand side and right side value need to be same. Now we can omit the keywords by using short hand `:=` 

```go
max_length := 100
```

Note that this statement is not the replacement of assignemnt operator. It is just the shorthand for the declaration + assignment. 

A `var` statement can be at package or function level. We see both in this example.

A var declaration can include initializers, one per variable. 
If an initializer is present, the type can be omitted; the variable will take the type of the initializer.

Example 

```go
package main

import "fmt"

var i, j int = 1, 2

func main() {
	var c, python, java = true, false, "no!"
	fmt.Println(i, j, c, python, java)
}
```

Inside a function, the `:=` short assignment statement can be used in place of a `var` declaration with implicit type.

Outside a function, every statement begins with a keyword (`var`, `func`, and so on) and so the `:=` construct is not available.

Variables declared without an explicit initial value are given their _zero value_.

The zero value is:

- `0` for numeric types,
- `false` for the boolean type, and
- `""` (the empty string) for strings.

We can also create the constants using `const` keyword. Constants need to be intiallized and so no datatype needs to be explicitly mentioned. Constants are declared using the `const` keyword. They can be character, string, boolean, or numeric values. The value must be known when the code is compiled. 

Go constants are unique because they can be "untyped," allowing them to interact flexibly with different types without explicit conversion.

```go
const Pi = 3.14159
const StatusActive = true
const WelcomeMsg = "Hello, Gopher!"
```

### Functions

Since go is the static and strongly typed language we need to declare the return type however there is no return type. functions are declared using the func keyword followed by the name of function and then return type. Similarly if we want to define the arguments we also need to define the type it accepts. However the variable name comes first followed by the data type. 

```go
func getData(a int,b int) string {
	return "Hello world"
}
```

Functions can return multiple things at once. However then we need to group the returns. In actual return separate values by the `,`. 

```go
func getData(a int) (float64,int){
	return 10.0,0
}
```

Finally we have something called named return here we can name the return values some value and then return based on that value names we just write return and whatever will be thev last values of that variables that would be returned

```go
func getData(a int)(ret1 int,ret2 int){
	ret1=10
	ret2=20
	return 
}
```

When two or more consecutive named function parameters share a type, you can omit the type from all but the last.

For example 

```go
x int,y int
// to 

x,y int
```

In go functions everything is passed by value and it does not stops at the top level. Rather if we are passing the nested structs all of them are copied recursively. 
### Type convertions

The expression `T(v)` converts the value `v` to the type `T`.
Example 

```go
var i int = 42
var f float64 = float64(i)
var u uint = uint(f)
```

Or simply 

```go 
i := 42
f := float64(i)
u := uint(f)
```

Unlike in C, in Go assignment between items of different type requires an explicit conversion. Try removing the `float64` or `uint` conversions in the example and see what happens.

When declaring a variable without specifying an explicit type (either by using the `:=` syntax or `var =` expression syntax), the variable's type is inferred from the value on the right hand side.

Constants are declared like variables, but with the `const` keyword. Constants can be character, string, boolean, or numeric values. Constants cannot be declared using the `:=` syntax.

```go
package main

import "fmt"

const Pi = 3.14

func main() {
	const World = "世界"
	fmt.Println("Hello", World)
	fmt.Println("Happy", Pi, "Day")

	const Truth = true
	fmt.Println("Go rules?", Truth)
}

```

### Function values

In Go, functions are **first-class citizens**. This means they aren't just static blocks of code; they are **values** that can be assigned to variables, passed as arguments to other functions, and returned from functions just like an `int` or a `string`.

You can assign a function (either a named one or an anonymous one) to a variable. The variable's type is defined by the function’s signature (its parameters and return values).

```go
func add(a, b int) int {
    return a + b
}

func main() {
    // Assigning a named function to a variable
    operation := add 
    
    // Using the variable to call the function
    result := operation(5, 10) 
    fmt.Println(result) // 15
}
```

A common pattern in Go is passing a function value into another function. This is often used for **callbacks** or defining custom behavior (like a strategy pattern).

Note that when function is passed it also has a type - 

The type is equivalent to the declaration. 

```go
<name_func> func(args) return_type 
```

Example 

```go
func compute(fn func(int, int) int) int {
    return fn(3, 4)
}

func main() {
    // Passing an anonymous function directly
    multiply := func(a, b int) int { return a * b }
    
    fmt.Println(compute(multiply)) // 12
}
```

#### Closures

This is where function values get powerful. An anonymous function can "capture" variables from its surrounding scope. The function "closes over" these variables, keeping them alive even after the outer function has finished executing.

```go
func incrementer() func() int {
    count := 0
    return func() int {
        count++ // This function "remembers" the count variable
        return count
    }
}

func main() {
    next := incrementer()
    
    fmt.Println(next()) // 1
    fmt.Println(next()) // 2
    
    another := incrementer()
    fmt.Println(another()) // 1 (starts its own separate count)
}
```
