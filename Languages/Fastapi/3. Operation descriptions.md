**Operation Descriptions** are the metadata you provide to explain what an endpoint does, what it expects, and what it returns. While your code is for the computer, these descriptions are for the **humans** (developers, frontend teams, or yourself in six months) who will use your API. 

### Status codes

We can set the status codes using the request object available as the argument of function. Note we need to get Response object from the fastapi package also fastapi provides status module to work with http status codes.

```python

from fastapi import Fastapi,status,Response

app = Fastapi()

@app.get("/path",status_code=200)
async def index(user_id:int,response:Response):
	response.status_code=status.HTTP_200_OK
	return {}
```

We can also tag our path to categorise them. For example we can categorise the apis into categories like `users`, `data` etc. We can also provide the summary and description and response_description. 

Note fastapi also threats long comment as description. All of this is provided as the swagger documentation. 

```python
from fastapi import Fastapi,status,Response

app = Fastapi()

@app.get("/path",
		status_code=200,
		tags=['blog'],
		summary="wegwe",
		description="sdvoi",
		response_description=""
		)
async def index(user_id:int,response:Response):
	response.status_code=status.HTTP_200_OK
	return {}
```
