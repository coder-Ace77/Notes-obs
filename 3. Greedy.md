An algorithm is said to be greedy if it makes the locally optimal choice at each step with the
hope of eventually reaching the globally optimal solution.

Problem must exhibit these two properties in order for a greedy algorithm to work - 

- It has optimal sub-structures. Optimal solution to the problem contains optimal solutions to the sub-problems.
- It has the greedy property. If we make a choice that seems like the best at the moment and proceed to solve the remaining sub-problem, we reach the optimal solution. We will never have to reconsider our previous choices.

#### Coin change

Consider coins of denomiations - `[1,5,10,25]`.  To make the req sum using minimum number of coins we always take the largest denomination not greater than remaining amount. 

It has optimal sub-structures and also satisfies greedy property. Same can not be said if we have `[1,3,4]`. For an instance creating 6 req `2` coins however greedy takes `4` and then needs to resort to `1s`.
